# Анализ лояльности пользователей Яндекс Афиши

Исследовательский анализ заказов билетов на Яндекс Афише за июнь–октябрь 2024 года. Цель — понять, какие пользователи чаще возвращаются на платформу и делают повторные заказы.

## Что сделано

- выгрузка данных из PostgreSQL SQL-запросом (с резервной загрузкой из CSV);
- предобработка: перевод выручки из тенге в рубли, типы данных, дубликаты, выбросы;
- профиль пользователя: признаки первого заказа, число заказов, средняя выручка, билеты, интервалы;
- анализ возвратов по сегментам, проверка продуктовых гипотез;
- корреляционный анализ phik;
- выводы и рекомендации для маркетинга.

## Основные результаты

- 61% пользователей делают повторный заказ, 28% — 5 и более заказов;
- чаще всего возвращаются пользователи, покупающие в среднем 2–3 билета (74%), реже всего — с заказами от 5 билетов (19%);
- с числом заказов сильнее всего связаны среднее количество билетов и средняя выручка с заказа.

## Запуск

```
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните параметры подключения к базе. Если база недоступна, данные загрузятся из CSV-выгрузки автоматически. Затем откройте `afisha_loyalty_project.ipynb` в Jupyter и выполните все ячейки.

## Стек

Python, pandas, matplotlib, seaborn, phik, SQL (PostgreSQL), SQLAlchemy
